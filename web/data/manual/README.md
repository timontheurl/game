# Händisch erfasste Saisons

Exportierte Dateien aus dem Erfassungs-Tool (`/erfassen` auf der Website) hier ablegen,
z. B. `oesterreich-bundesliga-2026-27.json`. Beim nächsten Build erscheint die Saison
automatisch mit Ranglisten, Spielerkarten, Vereinsseiten und Spielzügen.

Der Dateiname ist egal, entscheidend ist das Feld `slug` in der Datei.
